Changes From One Pager 

Random Egg Placement: 
Eggs are now moved to random spots throughout the garden when a new round starts. This was not in the original plan but I noticed that it needed more variety so I added a script that will check if the spot is empty.
Returning to the basket without all the eggs: I added an audio and message if the player returns to the basket before collecting all the eggs.
Sunset: The light, sun, moon, and sky color changes to show the timer
Art: The hay bales were replaced for trees.
Timer: The timer warning sound is removed because the round is short which is replaced with the sun setting and the sky darkening.
